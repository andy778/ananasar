# Layout: one entry per line, two spaces of indent per nesting level.
#   Caption  @ Shortcut  [flags]      an entry; flags: check, checked, disabled
#   ---                               a separator
#   + Caption ...                     an intentional addition of ours (allowed only after the
#                                     original entries of the same menu)
#   ~ field=value : reason            an intentional deviation, applies to the entry above.
#                                     field is kind, checked or enabled; ours may then have
#                                     either the original's value or this one.
#   !hidden Caption                   an entry the original hides; it must not appear anywhere.
# Captions are written without '&' mnemonics. "<n>" stands for the port number.
